Benvenutə nella tua Job Pipeline

Questa è la tua bacheca personale per cercare lavoro senza perdere il filo. Ogni offerta è una scheda con uno stato e, se la conosci, una scadenza.

1 · Aggiungi un lavoro

Premi Nuova in alto: incolla link, azienda, ruolo e (se c'è) la scadenza.

2 · Spostalo di stato

Clicca una scheda per aprire il menù e cambiarle stato (Candidato, Colloquio, Offerta…). I badge «N gg» / SCADUTO ti dicono cosa scade.

3 · Hai Claude Code o Codex? Fai lavorare l'AI 🤖

Claude Code e Codex girano nel terminale e sanno leggere il web e scrivere file: ti trovano le offerte e i graduate program e li valutano. Non serve saper programmare.

  1. Installa Claude Code (o Codex).
  2. Scarica il progetto: git clone https://github.com/javas-cri-pt/job-pipeline
  3. Entra (cd job-pipeline) e avvia claude o codex.
  4. Chiedi a parole tue: «Trovami graduate program in Europa e mettili nella board», «Leggi questo annuncio e dimmi se fa per me».
  5. Poi node push-board.mjs manda la board a questa app (PC + telefono). Dettagli nel RUNBOOK.md.

4 · Il codice è il tuo account

La board è sincronizzata ovunque usi lo stesso codice. Buona ricerca! 🍀
